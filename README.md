# simple-mini-oscilloscope

**基于 STM32F103C8T6 + ST7735S 的掌上示波器**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![MCU](https://img.shields.io/badge/MCU-STM32F103C8T6-blue.svg)](#31-平台)
[![IDE](https://img.shields.io/badge/IDE-Keil%20MDK%205.42-green.svg)](#81-开发环境)
[![PCB](https://img.shields.io/badge/PCB-oshwhub-orange.svg)](https://oshwhub.com/alexia0/project_qvtauhlg)

单通道采集、自动纵向缩放、边沿触发，同时显示峰峰值、频率、周期和占空比，并带一路固定 1 kHz PWM 输出。

| 项目 | 说明 |
|---|---|
| 硬件开源 | [立创开源硬件平台](https://oshwhub.com/alexia0/project_qvtauhlg)（原理图 / PCB / BOM） |
| 代码许可 | [MIT](LICENSE) |
| 固件体积 | Flash **27 KB** / 64 KB，RAM **3.5 KB** / 20 KB |
| 采样率 | 100 Sa/s ~ 500 kSa/s（6 档时基，20 µs/div ~ 100 ms/div） |

### 快速开始

```bash
git clone https://github.com/AlexiaQAQ/simple-mini-oscilloscope.git
```

用 Keil 打开 `MDK-ARM/oscilloscope-project.uvprojx` → **F7** 编译 → **F8** 下载（ST-Link / J-Link / DAP-Link 均可）。

## 1. 功能特性

| 功能 | 说明 |
|---|---|
| 单通道采集 | ADC1_IN9（PB1），12 位，300 点/帧 |
| 6 档时基 | 采样率 100 Sa/s ~ 500 kSa/s，T/div 100 ms ~ 20 µs（TIM2 定时触发 ADC） |
| 自动纵向缩放 | 任意幅度自动撑满显示区（Vpp ≥ 20 mV 即生效） |
| 边沿触发 | 上升沿，触发电平可调，步进随信号幅度自适应 |
| 自动测量 | 峰峰值 Vpp、频率、周期、占空比 |
| 双量程 | 1X / 10X，软件增益跟随，10X 时步进与限幅同步放大 |
| 暂停 | 旋钮按下冻结画面，LED 点亮 + 屏幕显示 `HOLD` |
| ADC 标定 | 上电自校准 + 零点校准（需输入接地） |
| PWM 输出 | TIM1_CH1（PA8），固定 1 kHz / 50%，常开 |

### 2.2 采集通道

| 项目 | 指标 |
|---|---|
| ADC | 12 位 SAR，ADCCLK 12 MHz，VDDA ≈ 3.2 V（实测） |
| 转换时间 | (SMP + 12.5) / 12 MHz，SMP 最小 1.5 周期 → **1.17 µs/点** |
| 采样率 | **100 Sa/s ~ 500 kSa/s**，6 档（TIM2 定时触发） |
| **ADC 硬件极限** | **857 kSa/s**（SMP=1.5，受 12.5 周期固定转换时间限制） |
| **理论带宽** | **250 kHz**（Nyquist = 500 kSa/s ÷ 2） |
| **实用带宽** | **约 50 kHz**（按 10 点/周期算，波形才看得清） |
| 时基 | **20 µs/div ~ 100 ms/div** |
| 垂直分辨率 | 1X：≈ 1.6 mV/LSB；10X：≈ 16 mV/LSB |
| 1X 量程 | ≈ **−1.3 V ~ +4.8 V** |
| 10X 量程 | ≈ **±13 V**（受前端 ±5 V 电源轨限制） |
| 输入阻抗 | ≈ 1 MΩ（820 k + 82 k + 100 k） |
| 耦合方式 | DC / AC（100 nF），机械拨动开关 |
| 前端传递特性 | `Uadc = 2.483 − 0.5065 × Vin`（1X 档实测） |
| 每帧点数 | 采样 300 点，绘制 154 点 |

> **带宽瓶颈分析**：整个系统是**采样受限**，不是模拟前端受限。
>
> | 环节 | 带宽 | 是否瓶颈 |
> |---|---|---|
> | ADC 采样（500 kSa/s） | 250 kHz（Nyquist） | ✅ 真瓶颈 |
> | TL072 闭环（增益 0.5） | ≈ 2 MHz | ❌ |
> | TL072 摆率 13 V/µs | 414 kHz @5 V 输出 | ❌ 大信号时接近 |
> | 分压网络 820 kΩ×10 pF | 19.4 kHz（已用 C8/C7 补偿展平） | ⚠️ 补偿精度受电容容差影响 |
> | 采样保持（1.5 周期 = 125 ns） | 源阻抗几十 Ω，τ≈1 ns | ❌ |
>
> 若把 TIM2 分频从 1 MHz 改成 4 MHz（Prescaler 71→17），最小触发周期可到 1.25 µs，
> 采样率提升到 800 kSa/s，Nyquist 达 400 kHz、实用带宽约 80 kHz。

### 2.3 测量能力

| 项目 | 指标 |
|---|---|
| 峰峰值 Vpp | 30 mV ~ 满量程，自动缩放，误差约 ±1% |
| 频率 | 约 **15 Hz ~ 200 kHz**（LM393 整形 → TIM3 捕获，1 MHz 时基，16 周期平均，±0.3%） |
| 频率显示 | 统一 3 位有效数字：9.90KHz / 47.0KHz / 470KHz / 999Hz |

### 3.3 模拟前端（外部电路）

输入信号分成两路：**采集通道**（到 ADC）和**测频通道**（到比较器）。

#### 采集通道

```
JK3(BNC) ─→ SW3(DC/AC, C17 100nF) ─→ SW4(1X/10X)
             ─→ R14 820k / R6 82k / R8 100k 分压（C8 10pF、C7 90pF 补偿）
             ─→ U6-A 缓冲 ─→ R10 20k ─→ U6-B 反相放大（R11 10k, C9 10pF）
             ─→ PB1 (ADC1_IN9)
```

- 输入阻抗 ≈ **1 MΩ**（820 k + 82 k + 100 k 串联到地）
- 反相放大倍数 **−R11/R10 = −0.5**，静态偏置由 R9 20k / R12 10k 从 +5 V 分压给出
- 实测传输特性（1X 档）：`Uadc = 2.483 − 0.5065 × Vin`

即 1X 档可测范围约 **−1.3 V ~ +4.8 V**，10X 档约 **±13 V**（再大就顶到运放的 ±5 V 电源轨）。

#### 测频通道

```
Uadc ─→ U4-A(LM393) 1IN−        ┐
        U4-A 1IN+ ← R15/R18 分压 ├─→ 1OUT ─→ PB0 (TIM3_CH3)
                                ┘
```

比较器把模拟信号整形成方波再送 MCU，所以**频率测量与 ADC 时基完全独立**——即使在 100 ms/div 档，频率读数依然准确。

> ⚠️ **比较器阈值是固定的**：1IN+ 由 R16 10k / R17 20k / R18 10k 分压 + R19 510k 正反馈决定，
> 约 **2.19 V**（对应 1IN− 即 Uadc 节点），换算到输入约 **0.58 V（1X）/ 5.8 V（10X）**。
> **信号不跨越这个电平时不会有边沿**，频率就测不到——固件会在 1.5 s 无捕获后显示 0。

> ⚠️ **注意**：AC/DC 与 1X/10X 都是**面板上的机械拨动开关**，固件读不到其状态。
> 1X/10X 的软件设置必须与开关一致（否则读数差 10 倍）；AC/DC 在屏幕上只是丝印图例。

## 4. 操作说明

### 4.1 按键

| 操作 | 功能 |
|---|---|
| **KEY1**（PB13） | 选中「量程」→ 旋钮切换 1X / 10X |
| **KEY2**（PB14） | 选中「时基」→ 旋钮切换 6 档 T/div |
| **KEY3**（PB15） | 选中「触发电平」→ 旋钮调节 |
| **旋钮旋转** | 调整当前选中项 |
| **旋钮按下** | 暂停 / 继续 |

选中的那一项会变成**黄底黑字**。

**按键扫描方式**：

- KEY1/2/3 走 EXTI（下降沿）中断，中断里只记时刻，主循环 5 ms 后确认（非阻塞消抖，硬件另有 100 nF）；
- 编码器按键 PA15 无 EXTI，软件边沿检测，**按下立即响应**，松手稳定 20 ms 后重新武装；
- 编码器 A/B 相（PB4/PB3）都走中断，用 **四边沿状态机**解码，抖动会形成"进-退"自动抵消；
  ENC_EDGES_PER_STEP 控制几个边沿走一步（当前 1）。

### 4.2 上电

1. **将输入短接到 GND**（零点校准需要 0 V 参考）；
2. 上电，等待约 0.5 s（期间完成 ADC 自校准、屏幕初始化、零点校准）；
3. 接入信号。

> **这一步是整个精度的关键。** 零点校准默认"此刻输入是 0 V"，如果上电时信号已经接上，
> 它会把当时的输入电平当成零点，之后**所有读数都带一个固定偏移**（表现为整条波形
> 平移，比如 0~3.2 V 的方波显示成 −0.3~2.9 V）。
>
> 判据：**整条波形一起平移、Vpp 仍然准确** → 就是零点错了，重新接地上电即可。
> 若是幅度本身不对（Vpp 也偏），那是量程或增益的问题，另查。

## 5. 界面布局

```
┌──────────────────────────────────────────────┐
│ AC/DC                                 1X/10X │ ← 固定图例
├──────────────────────────────────────────────┤
│                                              │
│              波形区 154 × 56                │◀ 触发电平三角
│                                              │
├──────────────────────────────────────────────┴──┤
│ ─┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬─      │ 横轴 + 刻度（每格 10 px）
│ VPP   1.02V    FRQ    47KHz                     │ 峰峰值 / 频率
│ PER  21.3us    DTY      50%                     │ 周期 / 占空比
│ 1X     210us        T1.00V                      │ 量程 / 时基 / 触发
└─────────────────────────────────────────────────┘
```

- **第一行**：峰峰值、输入频率。ADC 饱和时 Vpp 数值变**红色**（此时读数不可信，应换到 10X 档）。
- **第二行**：周期、占空比。
- **第三行**：三个可调项，选中项黄底高亮。
- 右侧 **◀ 红色三角**：当前触发电平的纵向位置；三角贴到上下边缘说明电平超出信号范围。

### 时基档位

采样由 **TIM2 定时触发 ADC**（1 µs 分辨率），所以采样间隔不受 ADC 转换时间限制，可以做到很慢；`T/div = 10 × 触发周期`。

| 档位 | ADC 采样时间 | TIM2 触发周期 | T/div | 采样率 | 每帧时长（300 点） |
|---|---|---|---|---|---|
| 1 | 1.5 周期 | 2 µs | 20 µs | 500 kSa/s | 0.6 ms |
| 2 | 28.5 | 5 µs | 50 µs | 200 kSa/s | 1.5 ms |
| 3 | 55.5 | 20 µs | 200 µs | 50 kSa/s | 6 ms |
| 4 | 71.5 | 200 µs | 2 ms | 5 kSa/s | 60 ms |
| 5 | 239.5 | 2 ms | 20 ms | 500 Sa/s | 0.6 s |
| 6 | 239.5 | 10 ms | 100 ms | 100 Sa/s | 3 s |

窗口时间 = 154 点 × 触发周期，最慢档约 **1.5 秒**，因此 **0.7 Hz 以上的信号都能看到完整周期**（再低只能看到波形的一部分）。

### 数据流

```
TIM2 定期触发 ADC ──DMA──> adc_value[300]
                         │ 传输完成中断：showbit=1，停 DMA
                         ▼
主循环 Scope_ProcessFrame()
   ├─ 换算电压 → voltageValue[300]，同时求 max/min
   ├─ 统计 Vpp / 占空比 / 饱和标志
   ├─ 重启 DMA（绘制期间数据继续累积）
   ├─ 边沿触发找起始点
   ├─ 逐点缩放 → drawCurve()
   └─ 画触发电平三角
                         │
                    UI_Refresh()  变化检测后重画读数
```

## 7. 关键参数与标定

### 7.1 换算链路

```
Vpin = code × ADC_VREF / 4095
Vin  = (zero_pin − Vpin) × ADC_FRONTEND_GAIN × (10X ? 10 : 1)
```

| 宏 | 值 | 含义 | 位置 |
|---|---|---|---|
| `ADC_VREF` | 3.334 V | 实测 VDDA | `app_scope.c` |
| `ADC_FRONTEND_GAIN` | 1.97 | 前端衰减比倒数 | `app_scope.c` |
| `zero_pin` | 上电实测 ≈ 2.483 V | 0 V 输入对应的引脚电压 | 运行时 |
| `WAVE_HALF_PX` | 24 px | 半幅占用的显示高度 | `app_scope.c` |

### 7.2 重新标定

**零点**：无需改代码——保证上电时输入接地即可自动测量。
若长期不接地使用，可修改 `ZERO_CAL_DEFAULT`（当前 2.37 V）。

**增益**：接入已知直流（如 1.000 V），看屏幕读数，按比例修正：

```c
ADC_FRONTEND_GAIN_new = ADC_FRONTEND_GAIN_old × 真实值 / 显示值
```

> 修改增益后零点不需要重标（零点由 `zero_pin` 独立测得）。
> 更换 VDDA 稳压、换板或改动前端电阻后需重新标定。

### 8.3 用 CubeMX 重新生成

`Core/` 会被覆盖，但其中已不含业务代码；`App/` 与 `Hardware/` 不受影响。生成后请确认：

- 编码器按键 **PA15** 仍为**上拉输入**（不是 EXTI）；
- 三个功能键 **PB13/14/15** 为 **EXTI 下降沿 + 上拉**；
- 编码器 **PB4/PB3** 为 **EXTI 双边沿 + 上拉**；
- ADC1 为 **外部触发 T2_CC2、连续转换关闭、DMA 循环**。

### 8.4 换板必做：重新标定

仓库里的标定值是**本板实测**，换一块板必须重测，否则读数会有固定偏差：

| 常量 | 位置 | 含义 |
|---|---|---|
| `ADC_VREF` | `app_scope.c` | 实测 VDDA（本板 3.334 V） |
| `ADC_FRONTEND_GAIN` | `app_scope.c` | 前端增益倒数（本板 1.97） |
| `ZERO_CAL_DEFAULT` | `app_scope.c` | 校准失效时的兜底零点（本板 2.37 V） |

标定步骤见 [7.2 重新标定](#72-重新标定)。

## 9. 已知限制

| 限制 | 说明 |
|---|---|
| 单缓冲 | 每帧采集完先拷贝到 `voltageValue[]` 再重启 DMA，绘图期间不会读到撕裂数据；但没有双缓冲，无法做连续流式采集 |
| 刷屏慢 | 逐像素/逐字节写 SPI，每写 2 字节翻转一次 CS，帧率受限于 SPI 吞吐 |
| 低频下限 | 单周期测量用 16 位计数器、只补偿一次回绕，约 **15 Hz** 以下读数不可信 |
| 1X 档负向余量小 | 引脚上限约 3.2 V，对应输入约 −1.3 V；测交流建议直接用 10X |
| 无垂直档位 | 只有自动缩放，无法锁定固定 V/div，幅度变化时波形会"呼吸" |
| AC/DC 不可感知 | 机械开关未接 MCU，屏幕标记需手动同步 |
| 无输入保护 | Uadc 可能被运放拉到负压，建议在 ADC 引脚加钳位（如 BAT54S + 串阻） |
| 采样率上限 | TIM2 以 1 MHz 触发，最快 500 kSa/s；ADC 本身能到 857 kSa/s，需改 TIM2 分频才能用满 |
| 慢档刷新慢 | 100 ms/div 时一帧要 3 s 才采完，波形约每 3 秒更新一次（真正的"卷动模式"） |
| 频率显示 | 3 位有效数字，9.90KHz 末位会随 ±0.3% 测量误差轻微跳动 |
| ~~TFT 白屏~~（已解决） | 面板首次上电会忽略初始化命令 → 白屏。`TFT_Init()` 现改为：硬件复位 → **SWRESET(0x01)** → 延时 → 初始化序列 → **最后才开背光**。若个别板子仍复现，把 `main.c` 的 `TFT_INIT_TWICE` 设为 **1** |
| **SPI 时钟偏高** | ST7735S 手册上限 15 MHz，本工程用 18 MHz（分频 4）。若出现花屏/白屏，可在 CubeMX 里把 SPI1 分频改成 8（9 MHz） |

## 10. 常见问题（FAQ）

| 现象 | 原因 | 处理 |
|---|---|---|
| **上电白屏** | 面板首次上电忽略了初始化命令 | `TFT_Init()` 已内置 SWRESET；若仍复现，把 `main.c` 的 `TFT_INIT_TWICE` 设为 1 |
| **整条波形平移，但 Vpp 准** | 零点校准采到了非 0 V 输入 | 上电前把输入短接到 GND，重新上电（见 [4.2](#42-上电)） |
| **读数差 10 倍** | 面板 1X/10X 开关与软件设置不一致 | KEY1 选中量程，用旋钮切到与开关一致 |
| **0~3.3 V 方波底部显示成负值** | AC 耦合去掉了直流分量，波形以 0 V 为中心 | 把 SW3 切到 DC 耦合 |
| **不接信号 Vpp 显示 0.02 V 左右** | ADC 噪声底 | 低于 30 mV 一律显示 0，属正常 |
| **频率显示 0，或突然掉到 0** | 信号不跨比较器阈值（约 0.58 V @1X / 5.8 V @10X），或 1.5 s 无捕获 | 加大信号幅度，或改 R17 降低阈值（见 [3.3](#33-模拟前端外部电路)） |
| **频率长时间不刷新** | 16 周期平均，低频下更新慢 | 15 Hz 时约 1 秒更新一次，属正常 |
| **旋钮转一格跳两下 / 两格才走一步** | 编码器边沿数与 `ENC_EDGES_PER_STEP` 不匹配 | 改 `app_key.c` 里的宏（1 / 2 / 3 / 4） |
| **旋钮方向反了** | A/B 相接线相反 | 对调 `KEYAPRESS` / `KEYBPRESS` |
| **慢档波形几秒才更新一次** | 定时采样，100 ms/div 时一帧要 3 s | 正常现象，相当于"卷动模式" |
| **编译报 `Could not open via file ….__i`** | 输出目录里混了旧构建产物 | 清空 `MDK-ARM/oscilloscope-project/` 后重建 |

更多限制见 [9. 已知限制](#9-已知限制)。
